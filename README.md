# +iForma

Bloques a línea para plantas, alzados y perspectivas.

+iForma convierte fotografías y dibujos en bloques a línea (personas, vegetación, mobiliario, vehículos, objetos) sobre fondo blanco o transparente, listos para Photoshop o CAD.

- **Cuatro pasos:** imagen (perspectiva y escala real), trazo (recorte, ignorar sombras, enderezar líneas), líneas (tres grosores, borde de la imagen, goma) y guardar.
- **Biblioteca por carpetas:** se guarda en este navegador; descárgala en .zip para tener copia.
- **Exportación:** PNG transparente o blanco (también a escala a 300 ppp) y DXF por capas (MF_CONTORNO, MF_PRINCIPALES, MF_DETALLE), en milímetros reales si se marca una escala.
- **Privacidad:** las imágenes se procesan en el propio dispositivo y no se envían a ningún servidor.
- Funciona sin conexión y se puede instalar como app.
